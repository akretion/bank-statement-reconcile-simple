Bank Statement Completion from Label - Sale extension
=====================================================

This module is a small auto-install module for Odoo installations that used both the OCA module **sale_commercial_partner** (from the github project `OCA/sale-workflow <https://github.com/OCA/sale-workflow>`_) and the community module **account_statement_completion_label_simple**.

It adds an option **Sale Order Number Completion** on the configuration of bank journals. If you enable this option, when you import a bank statement and a bank statement label contains the number of a sale order or quotation, Odoo will automatically set the commercial partner of that sale order/quotation on the bank statement line.

See the README of the module **account_statement_completion_label_simple** for more information.
